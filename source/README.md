# Bang Shoot! original files

Every original file used to make the game, kept in one place: the music from Suno and the artwork from Gemini, at full quality, exactly as they were created.
The game itself (`index.html`, `test.html` and the `music` folder) uses processed versions of these: backgrounds removed, trimmed, looped and resized. The originals are kept here so anything can be re-made at full quality later.

To download everything at once, use the green **Code** button on the repository's main page, then **Download ZIP**.

Note: this repository is public, so anyone can view and download these files.

## Sound effects made in code

Folder: `source/sound-effects/made-in-code/`

47 sound effects synthesised in code (retro arcade style, like the old sfxr tool) to replace the game's old beeps, which were too quiet to hear. Each `.wav` here is the full-quality version; the game uses 22 kHz copies. The scripts that made them are in the same folder, so any sound can be changed and remade: `python3 build.py` (needs Python with numpy and scipy). `vol.json` sets each sound's in-game volume.

| Group | Files |
|---|---|
| Bullet hits | hit-pulse, hit-laser, hit-wave, hit-homing |
| Firing loops | fire-pulse, fire-laser, fire-wave, fire-homing |
| Ship | player-hurt, low-health |
| Weapons | charge-loop, charge-release, weapon-swap, missile-launch, bomb-drop |
| Enemies | enemy-missile, armour-chip, armour-clang, cloaker, dive, kamikaze, crystal-shot, spit, egg-burst, carrier-launch, crystal-fall |
| Bosses and warnings | boss-tell, boss-launch, crystal-break, new-enemy, rear-warning, tunnel-warning, miniboss-arrive, miniboss-rage |
| Stage 5 | door-alarm, door-blast, foundry-alarm, press-warning, press-slam, zap-charge, zap-fire, titan-build |
| Menus and ending | menu-move, menu-select, text-tick, firework, hyperdrive |

## Sounds built from real recordings

Folder: `source/sound-effects/kenney-based/`

Built from Kenney's Impact Sounds pack (CC0, see `Kenney-License.txt`; credited in the game's end credits though it isn't required), sometimes layered with the game's own Suno explosions.

| File | Used for |
|---|---|
| clang-tick-0 to 4 | Light hit on every shot that bounces off armour |
| clang-heavy-0 to 4 | Heavy armour impact, about every half second while hitting armour |
| chip-small-0 to 2 | Small pieces chipping off a boss |
| armour-chunk | Big pieces breaking off a boss (small explosion + plate crash + wreckage) |
| crystal-break | Crystal Queen's crystals breaking off (small explosion + glass) |

The taking-damage sound (`made-in-code/player-hurt.wav`) is the "thud and alarm" version.
