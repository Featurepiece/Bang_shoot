# Bang Shoot! original files

Every original file used to make the game, kept in one place: the music from Suno and the artwork from Gemini, at full quality, exactly as they were created.
The game itself (`index.html`, `test.html` and the `music` folder) uses processed versions of these: backgrounds removed, trimmed, looped and resized. The originals are kept here so anything can be re-made at full quality later.

To download everything at once, use the green **Code** button on the repository's main page, then **Download ZIP**.

Note: this repository is public, so anyone can view and download these files.
